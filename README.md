# Tasks & Reminders Widget

Install the APK built with GitHub Actions, open the app, and add the Tasks & Reminders home-screen widget. It shows the three newest unfinished tasks. Tapping the widget shows all items. The plus button opens the task editor. Each task offers a daily, once, or none reminder. Reminder notifications can play sound and appear as a heads-up/full-screen alert when Android permits. Dismiss only, no snooze. For reliable exact times, enable Android's Alarms & reminders permission and notifications. Android 14+ may restrict full-screen alert privileges; then heads-up notifications are used instead.

The APK is signed with the standard debug development key for personal installation; not for Play Store distribution.

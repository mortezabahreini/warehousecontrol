# شمارنده پارمین (Parmin Counter)

A simple offline Android app for counting positive and negative behavior, intended for a parent to track their child's week or other chosen period.

- Tap the green +1 button for good actions.
- Tap the pink +1 button for actions needing improvement.
- Correct accidental taps with the -1 link on each card.
- Values are saved immediately on the phone, with no sign-in or internet.
- A period runs until you choose "ثبت نتیجه و شروع دوره جدید".
- The final counts of previous periods are stored and can be opened under "مشاهده دوره‌های قبلی".

## Installation

Download `ParminCounter.apk` from the GitHub Releases page and install on Android 8 or newer. The release is signed using the default Android debug signing key for direct personal installation, not Play Store distribution.

## Privacy

No permissions are requested, no background tasks, and no network calls. Local SharedPreferences only.
